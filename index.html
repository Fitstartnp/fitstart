Privacy warning: A private GitHub Gist is not end-to-end encrypted. GitHub stores the sync data; anyone with access to that GitHub account can read it. A GitHub Personal Access Token grants account access. FitStart keeps the token only in this browser tab and does not save it across reloads. Do not put a token in a URL or share it. To move data to another device, use Export JSON Backup and Import. Shared live sync for two people should use a private backend with separate logins.
